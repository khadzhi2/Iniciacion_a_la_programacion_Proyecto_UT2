# Alpine&Run

Aplicación de consola en C# para gestionar la tienda de ropa y zapatillas deportivas Alpine&Run.

## Funcionalidades
- Cobrar una compra: marca, modelo, cantidad, extras, entrega (recogida o envío), descuento por cantidad, pago y cambio.
- Ticket de cada compra.
- Consultar inventario.
- Consultar ventas del día (operaciones, recaudación, importe medio y operación más cara).
- Reponer inventario.

## Requisitos
- .NET SDK [versión, por ejemplo 8.0]

## Cómo ejecutarlo
1. Clona el repositorio: git clone [URL del repositorio]
2. Entra en la carpeta del proyecto.
3. Ejecuta: dotnet run
